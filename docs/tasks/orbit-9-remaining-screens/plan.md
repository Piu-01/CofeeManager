# Kế hoạch triển khai tiếp Orbit 9

Người dùng đã cho phép triển khai tám màn sau giai đoạn mẫu. Thực hiện tuần tự, không delegate, không thay backend. Kế thừa yêu cầu build/chạy/test/tự sửa đã giao từ đầu. Ghi source baseline trước sửa và giữ source cố định từng lượt kiểm.

1. Mở rộng OrbitListWorkspace bằng vùng tabs và chế độ tools/meta theo HTML; default inventory giữ nguyên. OrbitDataGridView có profile metrics từ design-tokens, badge Status/Tier chỉ theo màn (không icon tên hạng). Pagination thêm trình bày serverpage không bịa tổng. EmptyState hỗ trợ trạng thái chưa chọn khách. Verify inventory default không drift hình thức, không ghi query trong control dùng chung.
2. Tạo OrbitRecordListControl dùng workspace mới, tái sử dụng vòng đời query/loading/cancellation/selection/actions của RecordListControl. Chỉ tám màn chuyển sang base mới; CustomerOrderList giữ base cũ để không đổi dialog ngoài scope. Giữ skip50, typed DTO/revision, role visibility và handler async. Thêm/refresh/pager giữ event một lần. Gắn filter hiện có với reset/reload qua UI, không thay contract.
3. ProductsControl chỉ đổi layout/base và metadata; đưa Công thức trước Sửa/Xóa, Thêm góc phải; category/selling/refresh cùng toolbar. Edit/Recipe/Delete body giữ nguyên. Verify format tiền, lọc, quyền ADMIN/STORE/CASH, editor mở đúng row.
4. OrbitManagementTabs thay cơ chế di chuyển heading bằng thanh tab native Button và host pages, để mỗi page giữ nguyên header/primary và tabs đặt dưới heading. Tables/Loyalty dùng chung. Grid bàn dùng OrbitTableCard native có trạng thái chữ + màu và selection; giữ SelectCode gọi service thật. AreaList dùng grid profile28px. Verify hai mode, filter, selection, toolbar/footer đứng yên.
5. CustomersControl dùng base mới; Mở sổ điểm/Hóa đơn/Sửa/Xóa theo mẫu. Picker giữ action hiện có, không mất CustomerSelected hoặc reload sau ghi. Points/Tier/Discount typed chỉ đọc, badge không đổi code.
6. PromotionList/PolicyList/PointList dùng base mới. Policy tools không có search, Tải lại cùng count; points Chọn khách+identity ở tools và empty icon ở body, Điều chỉnh điểm primary. Giữ preview/confirmation/history readonly và dialog date đã sửa. Không đổi code use case.
7. CatalogsControl/Designer thay wiring layout cũ bằng workspace/tabs/grid chung; giữ tên fields và toàn bộ editor/delete/reconcile/RefreshRows contract. Thay compact reparent tabs cũ không còn dùng bằng strip cuộn native khi chật. Giữ bảy tab/kiểu cột thật, checkbox Supported readonly, Search_Click/Reload_Click/Prev/Next/Add/Edit/Delete gốc; chỉ đổi chỗ và kiểu vẽ. Dọn field/helper dư của lần thay, kiểm mọi tham chiếu trước xóa.
8. Kiểm tra build, source backend/hash handler, bộ rules hiện có. Probe trong process chỉ kiểm control/binding/metrics và role, không coi là native GUI acceptance. SQL test chỉ đúng DB test marker; không ghi dữ liệu thật. Native app manual login, điều hướng và chụp tám màn + ảnh inventory regression, thử search/filter/tab/pager/mode/empty/editorcancel/resize/DPI. Nếu cần đổi Scale, nói rõ và nhờ người dùng khi công cụ không làm được. Lưu FAIL trước tự sửa scope visual rồi regression lượt mới.
9. Bàn giao report.md/test-results.md/audit.md, ảnh app thật và giới hạn; không tự nâng T01–T32. Giữ code còn dùng ở dialog/ngoài scope, không xóa lịch sử UI cũ hay references.

Files chính: UI/OrbitListWorkspace.cs, OrbitDataGridView.cs, OrbitPagination.cs, OrbitEmptyState.cs, OrbitButton.cs, OrbitManagementTabs.cs; mới OrbitSectionTabs.cs, OrbitRecordListControl.cs, OrbitTableCard.cs; Modules/Menu/ProductsControl.cs, Tables/TablesControl.cs, Customers/CustomersControl.cs, Loyalty/LoyaltyControl.cs, Catalogs/CatalogsControl.cs vàDesigner.
