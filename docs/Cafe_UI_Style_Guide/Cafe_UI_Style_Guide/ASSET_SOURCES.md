# Nguồn asset

- Icon: Lucide npm package 1.8.0 từ bản cài runtime, https://lucide.dev và https://github.com/lucide-icons/lucide. ISC; một số icon kế thừa Feather có điều kiện MIT. Giữ nguyên assets/icons/LICENSE.txt (toàn bộ nội dung package). SVG giữ hình học gốc, đổi màu; PNG chuyển từ SVG.
- Lucide script offline: cùng package, assets/vendor/lucide.min.js; license ở assets/icons/LICENSE.txt.
- Ảnh món: minh họa vector nguyên bản được tạo bằng mã cho guide này, không phải ảnh chụp/stock/ảnh thương hiệu; có thể sửa và dùng cho dự án. Tên file americano/latte/matcha/tea. Không mô tả là ảnh món thật.
- Placeholder và logo chữ: được tạo bằng mã cho bộ guide, tên AMERICANO chỉ là mẫu và cần thay khi chốt tên quán. Không bảo đảm độc quyền tên/logo.
- Không kèm ảnh stock bên thứ ba. Khi thêm ảnh thật/stock: ghi URL file gốc, tác giả, ngày tải, giấy phép và yêu cầu attribution vào đây; quyền dùng logo/nhãn hiệu xét riêng.
- Font Segoe UI tham chiếu font hệ thống Windows; không phân phối file font. Browser dùng fallback Arial/sans-serif.
