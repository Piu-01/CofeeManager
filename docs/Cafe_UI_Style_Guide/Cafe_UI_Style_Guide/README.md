# Café UI Style Guide

Giải nén toàn bộ ZIP, mở index.html bằng Edge/Chrome. Giữ cấu trúc assets và preview.html cạnh index.html. Không cần Internet, npm hoặc server. Không mở file HTML ngay trong trình xem ZIP.

Guide gồm 7 nhóm, 26 icon với SVG màu nâu/kem và PNG 16/20/24/32px, 4 ảnh minh họa demo + placeholder, 3 logo mẫu, và POS/list/control preview tương tác. Không phải app kết nối SQL.

Đưa vào docs/ui-guide/ của dự án; dùng các màu/font/quy ước để hiện thực AppTheme và form. Chỉ copy asset cần dùng sang Resources; giữ license. Ảnh thật thay asset demo theo cùng tỷ lệ 4:3.

Bảng màu được lấy từ bản Espresso đã xem thử; người dùng mới nhận xét tạm ổn, guide vẫn là đề xuất để chốt sau khi kiểm tra WinForms thật.
